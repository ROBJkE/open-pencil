# Desktop (Iced)

The desktop GUI is an Iced application in `desktop/src`. It is not a webview. Release versions are set in `desktop/Cargo.toml` (`tools/AGENTS.md`, Releases). Run it from a repository checkout with `bun run desktop` after `bun install` and `bun run build:packages`.

- The window, menu bar, and canvas chrome live in `desktop/src/main.rs`. File, Edit, View, and Object menus call the editor session; they do not embed the Vue app.
- Document open and save use the native file dialog (`rfd`) and the session methods `open`, `save`, and `saveAs`. Save in place is limited to `.fig`. Opening a `.pen` file and choosing Save asks for a `.fig` path.
- The editor session is a newline-delimited JSON process the Iced app spawns: `packages/cli/src/desktop-session/serve.ts`, started with Bun. It drives public `@open-pencil/core` and `@open-pencil/scene-graph` APIs. `OPENPENCIL_SESSION_HOST` overrides the script path and `OPENPENCIL_BUN` overrides the Bun binary. A release binary still needs Bun and a built checkout unless that host path is bundled beside it.
- `cd desktop && cargo test` covers the session protocol parser. Rust 1.88 or later is required (`desktop/rust-toolchain.toml`).
- Linux builds need `pkg-config`, `libxkbcommon`, Wayland, Vulkan, and GTK 3 development packages. File dialogs need GTK or an XDG desktop portal at runtime.
- Brand icons under `desktop/icons` are generated by `bun run generate:icons --target desktop` and are not loaded by the Iced window.
